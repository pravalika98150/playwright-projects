# LearnPlaywright3x

A JavaScript learning repository focused on fundamentals, practice exercises, and automation notes.

## Repository Structure

- `chapter_01_Basics/` — Hello world and basic syntax
- `chapter_02_JS_Concepts/` — `let`, block scope, and hoisting
- `03_chapter_Identifier/` — identifiers, naming rules, and comments
- `04_chapter_Literal/` — literals, null, undefined, and number formats
- `05_chapter_Operator/` — arithmetic, comparison, logical operators, and coercion
- `06_chapter_Statement/` — control flow and decision statements
- `07_chapter_switch/` — `switch` statement patterns and examples
- `08_UserInputs/` — user input and file system examples in Node.js
- `09_chapter_Loops/` — loops, iteration, and nested loop examples
- `HackerRank/` — practice problems for conditional and switch logic
- `IQ_Notes/` — reference notes, interview prep, and documentation

## Notes

The `IQ_Notes` folder contains extended notes and reference documents for concepts like source code, bytecode, binary, and other core JavaScript topics.
